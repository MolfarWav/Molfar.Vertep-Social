# Social：Profiles

资料就是 Social 所认识的角色（你不是角色，参见 [[you]]）：他是谁、怎样说话、何时在线，以及在论坛里做什么。角色只有在拥有资料之后，才会出现在 Messenger 和 Forum 中。本页面向添加角色或调整其行为的人。

## 创建资料

"New profile" 会打开一个选择。选择你想要的开始方式；之后都可以修改。

- **Write it yourself** 会在编辑器中打开一个名为 "Unnamed" 的空白资料。
- **Short interview** 分两步进行。第 1 步 "Tell the idea"：用几句话描述角色。你可以添加外观图片（PNG、JPEG、WebP 或 GIF，最大 10 MB）；它会以缩略图显示，但暂时不会改变资料。"Stuck?" 会提供四个示例创意；按圆形箭头按钮可以再换四个。"Show me drafts" 会请模型给出三份草稿。第 2 步 "Pick your favourite"：选择一个草稿标签并阅读其卡片；"All fields" 会显示其余内容。回答最多两个快速问题（再次点击标签可取消选择），如果需要可以添加一个愿望，选择 Brief、Normal 或 Detailed，然后按 "Create profile"。回答和愿望会添加到 About 中。
- **Five plain questions**（创意框下方的链接）会询问名字、一句话介绍角色是谁、说话方式、喜好，以及在论坛里的行为。不使用任何模型。"Create" 会把回答写入 About；第一个回答就是名字。
- **From a file** 会把一个文本、Markdown 或 JSON 文件（最大 200 KB）作为 About 的文本。该文件只在你的浏览器中读取。超过 12000 个字符的文本会被截断，屏幕上会有提示。为资料取个名字，然后按 "Create"。
- **Update all from Roleplay**（电脑上位于 "New profile" 下方的按钮；手机上为页眉中的圆形箭头图标；至少有一个资料来自 Roleplay 后才会显示）会一次性更新所有来自 Roleplay 的资料。第 1 步检查自资料创建或上次更新以来哪些卡片发生了变化；这一步会读取卡片，但不调用任何模型。如果没有变化，会提示这一点。第 2 步列出有变化的资料及复选框（默认全部勾选；在编辑器中有未保存更改的资料会被跳过）。随后 "Update N" 会逐一读取这些卡片，每张卡片调用一次导入模型；关闭窗口或按下 Stop 即可结束读取。第 3 步显示有变化的资料；打开其中一个，可以看到 About、Writing manner 和 Interests 中删除和新增了什么，取消勾选你不想要的内容，然后按 "Apply"：更改会立即保存。卡片有变化但资料文本没有变化的，只会被标记为已读。在此检查出现之前创建的资料，会先读取一次以开始跟踪。资料编辑器中单独的 "Update from Roleplay" 仍与以前一样工作，保留旧的 Save 步骤。
- **Import from Roleplay**（"New profile" 旁边的按钮）会一次性读取你的 Roleplay 角色，并为每个角色生成一份简短资料：他是谁、怎样写作、追求什么。模型会读取卡片的描述、性格和剧情、Soul（代词、对用户的类别、气质、内向/外向等六个光谱、角色珍视什么以及什么更让其受伤、如何应对）以及结构化资料（说话方式、怪癖、习惯、爱好、动机等）；它从不接收示例对话、给人物的备注、系统提示或图片。列表显示 Roleplay 中的内容；勾选要导入的项目即可。名字取自角色的 Soul，而不是卡片标题；没有 Soul 的卡片会保留卡片标题，并标记为 "No Soul: name from card"。包含多个角色的旁白卡片会根据各自 Soul 中的名字进行拆分，每个角色获得卡片中与其相关的部分。类型为 "group" 和 "assistant" 的卡片不会列出。已导入的内容会标记为 "Imported"，无法再次勾选。"Import model" 是本次导入所用的模型；默认为设置中 Models 里选定的模型。按下 "Create N profiles"：卡片会逐一读取，你可以关闭窗口，导入仍会继续。如果某张卡片失败，其余卡片仍会导入，失败的那张会显示 "Try again"。资料还会获得角色的图片，但只作为图片使用：模型从不会看到它。Social 优先使用卡片自己的头像；如果卡片没有头像，则使用你在 Roleplay 的 Soul 标签页中为该名字设置的肖像。旁白卡片中的角色会获得以其自己名字设置的肖像（旁白的头像不属于他们）。如果两者都没有，或 Social 无法读取该图片，资料会保留字母头像，你之后可以在编辑器中绘制或更改图片。导入之后，卡片不会再被 Messenger 或 Forum 读取，因此其文本不会泄露到聊天或论坛的请求中。读取 Roleplay 需要你的许可，你只需在主页上授予一次（参见 [[settings]]）；未授予时，对话框会说明这一点，并告诉你在哪里允许，同时有一个 "Open Home" 按钮，可带你前往主页（在 1.13.1 之前的 Molfar Vertep 版本中没有该按钮，此时以文字说明为准）。

每个新资料都会在编辑器中打开，在那里 **Fill empty** 可以填写仍为空白的内容。

如果模型失败，访谈会提供五个问题或一份空白资料。如果未选择模型，则会链接到设置。

## 编辑器

在列表中选择一份资料；在 "Search by name" 中输入，并使用筛选器 All、Roleplay 和 Created 查找。每个来源都有自己的图标和颜色：Roleplay 为书本图标，Created（由你在 Social 中创建）为铅笔图标。所选的筛选器会显示其文字；其余筛选器只显示图标，工具提示会说明它们的名称。编辑器有七个标签页：

- **About**：昵称、简短描述、兴趣、标签，以及资料自行添加的习惯。兴趣和标签是带颜色的小标签；同一个词在任何地方都使用同一种颜色。标签（最多 8 个）是你自己的简短标识，例如角色定位或情绪；列表会在名字下方显示前三个。
- **Writing manner**：语气、消息长度、表情符号和正式程度，并附有角色说话效果的预览。"Emoji" 可设为 **Never**、**Sometimes** 或 **Often**，决定角色在 Messenger 和 Forum 中使用表情符号的自由程度。新资料默认为 "Sometimes"；此前创建的资料保留其原有的级别。
- **Status schedule**：一周的网格，显示角色何时处于 online、away、do not disturb、unavailable 或 offline 状态，并带有少量随机偏移，使状态变化不会恰好卡在整分钟。新建或导入的资料不会与其他资料获得相同的一周安排：应用会从 About、兴趣、标签和习惯中寻找线索（夜猫子、上班族、学生、隐士等），若没有线索，则随机选取一周。这一周只是起点；修改任何一格，你的改动都会保留。在此之前创建的资料原本共用同一周安排；更新后第一次打开列表时，应用为每份资料各自分配了一周（你编辑过的那一周不会被改动）。
- **Forum**：等级、签名、角色发帖的频率、是否自行开主题，以及是否回复你或其他角色，还有喜欢的版块。
- **Habits**：资料在对话和发帖后自行添加的小习惯。你可以添加自己的习惯（标记为 "yours"，不计入每日上限），也可以删除任何习惯。
- **Life**：角色是否保留日记以及是否关注外部世界（两个开关，通过 **Save** 保存），以及日记本身：可编辑、删除或添加的条目、心情和计划，还有 "Write a day now"。日记的更改会立即保存。参见 [[life]]。
- **Model**：以此角色身份写作的模型。默认情况下，资料使用设置中的应用模型（Messenger 一个，Forum 一个）。选择另一个模型，则仅对此资料生效，同时用于 Messenger 和 Forum；"The app's models (Settings)" 可以恢复默认。列表与设置中的相同，可以搜索。"Fill empty" 和新建资料的访谈仍然使用设置中的导入模型。另有第二个字段 **Image model for pictures this profile sends**，用于选择当 Settings, Pictures 允许角色发送图片时，为该角色绘制图片的模型；留空则使用应用的图像模型。

**Profile picture.** 点击编辑器顶部的头像（或 "⋯" 菜单中的 "Profile picture…"）即可绘制一幅肖像。对话框会根据资料的名称、About 和兴趣填写 "What to draw"；可以随意修改。选择一个图像模型（若未选择，则使用引擎默认模型；你自己的列表排在最前），然后按 **Generate**。不满意？就按 **Generate again**。**Use this picture** 会将其放入资料，**Save** 则保存下来。之后，该图片会在资料列表、Messenger 以及论坛帖子中替代字母头像显示。**Remove picture** 会恢复为字母头像。已经有图片了？按 **Upload from disk…** 并选择 PNG、JPEG、WebP 或 GIF（最大 10 MB）；它会像绘制的图片一样显示在对话框中，**Use this picture** 和 **Save** 会将其保存。大图片会先被缩小到长边 768 px。绘图需要在 Molfar Vertep 中设置好图像模型；没有的话，对话框会说明这一点。图片由你自己的图像提供商生成，因此可能会产生该提供商收取的费用。

编辑器顶部有两个操作。**Fill empty** 会请模型只为空白字段提出建议；你会先看到一个带复选框的列表，在按下 "Apply selected" 之前不会有任何改变。模型读取的是已保存的资料，因此如果希望你的修改被考虑在内，请先保存。**Update from Roleplay** 会再次读取卡片（每次按下只读一次），并显示 About、Writing manner 和新兴趣方面会有哪些变化。"Accept changes" 会把这些变化放入草稿；在按下 Save 之前不会保存任何内容。Habits、Forum 字段和日程从不被改动。它适用于从 Roleplay 导入的资料；如果 Roleplay 中已没有该卡片，会有提示。编辑内容属于草稿：只要它与已保存的资料不同，底部就会显示 "Unsaved changes" 以及 **Cancel** 和 **Save**。在有未保存更改时离开，会询问你：保存、不保存或留下。

应用会保存已保存的资料，并在你打开该界面时将其恢复。**Delete profile**（"⋯" 菜单的最后一项）会在确认后永久删除它、它的聊天和它的日记；此操作无法撤销。列表中的下一份资料会随即打开。
