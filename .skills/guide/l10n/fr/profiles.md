# Social : Profiles

Un profil est un personnage tel que Social le connaît (vous n’en êtes pas un : voir [[you]]) : qui il est, comment il écrit, quand il est online et ce qu’il fait sur le forum. Les personnages n’apparaissent dans le Messenger et sur le Forum qu’une fois qu’ils ont un profil. Cette page s’adresse à ceux qui ajoutent des personnages ou règlent leur comportement.

## Créer des profils

« New profile » ouvre un choix. Choisissez comment commencer ; tout peut être modifié plus tard.

- **Write it yourself** ouvre un profil vierge nommé « Unnamed » dans l’éditeur.
- **Short interview** se déroule en deux étapes. Étape 1, « Tell the idea » : décrivez le personnage en quelques mots. Vous pouvez ajouter une image de son apparence (PNG, JPEG, WebP ou GIF, jusqu’à 10 Mo) ; elle s’affiche en miniature et ne modifie pas encore le profil. « Stuck? » propose quatre exemples d’idées ; appuyez sur le bouton rond fléché pour en obtenir quatre autres. « Show me drafts » demande au modèle trois brouillons. Étape 2, « Pick your favourite » : choisissez un onglet de brouillon et lisez sa carte ; « All fields » affiche le reste. Répondez à deux questions rapides au maximum (touchez une puce une seconde fois pour l’effacer), ajoutez un souhait si vous le souhaitez, choisissez Brief, Normal ou Detailed, puis appuyez sur « Create profile ». Les réponses et le souhait sont ajoutés à About.
- **Five plain questions** (le lien sous la zone d’idée) demande un nom, une ligne sur ce que le personnage est, sa façon de parler, ce qu’il aime et ce qu’il fait sur le forum. Aucun modèle n’est utilisé. « Create » écrit les réponses dans About ; la première réponse est le nom.
- **From a file** prend un fichier texte, Markdown ou JSON (jusqu’à 200 Ko) comme texte d’About. Le fichier est lu uniquement dans votre navigateur. Les textes de plus de 12 000 caractères sont coupés, et l’écran l’indique. Donnez un nom au profil, puis appuyez sur « Create ».
- **Import from Roleplay** (aussi un bouton à côté de « New profile ») lit une fois vos personnages Roleplay et crée de chacun un court profil : qui il est, comment il écrit, ce qui le fait vivre. Le modèle lit la description, la personnalité et le scénario de la carte, la Soul et le profil structuré ; il ne reçoit jamais les dialogues d’exemple, les notes pour les personnes, le prompt système ni l’image. La liste montre ce que Roleplay contient ; cochez ce que vous voulez importer. Le nom vient de la Soul du personnage, pas du titre de la carte ; une carte sans Soul garde le titre de la carte et porte la mention « No Soul: name from card ». Une carte de narrateur avec plusieurs personnages est découpée selon les noms dans leurs Souls, et chacun reçoit la partie de la carte qui le concerne. Les cartes de types « group » et « assistant » ne sont pas proposées. Ce que vous avez déjà importé est marqué « Imported » et ne peut plus être coché. « Import model » est le modèle de cette importation ; par défaut, c’est celui de Settings, Models. Appuyez sur « Create N profiles » : les cartes sont lues les unes après les autres, et vous pouvez fermer la fenêtre, l’import continue. Si une carte échoue, les autres s’importent quand même et la carte en échec affiche « Try again ». Après l’import, la carte n’est plus relue par la messagerie ni par le forum, donc son texte ne fuit pas dans les requêtes de chat ou de forum. La lecture de Roleplay demande votre autorisation, que vous donnez une fois sur Accueil (voir [[settings]]) ; sans elle, la fenêtre l’indique et dit où l’autoriser.

Chaque nouveau profil s’ouvre dans l’éditeur, où **« Fill empty »** peut remplir ce qui est encore vide.

Si le modèle échoue, l’entretien propose les cinq questions ou un profil vierge. Si aucun modèle n’est choisi, il renvoie vers les paramètres.

## L’éditeur

Choisissez un profil dans la liste ; saisissez « Search by name » et utilisez les filtres All, Roleplay et Created pour en trouver un. Chaque source a sa propre icône et sa couleur : un livre pour Roleplay, un crayon pour Created (créé par vous dans Social). Le filtre choisi affiche son nom ; les autres n’affichent que l’icône, et une info-bulle les nomme. L’éditeur comporte six onglets :

- **About** : pseudo, courte description, centres d’intérêt, tags et les habitudes que le profil ajoute de lui-même. Les centres d’intérêt et les tags sont des pastilles colorées ; un mot garde la même couleur partout. Les tags (jusqu’à 8) sont de courtes étiquettes de votre choix, comme un rôle ou une humeur ; la liste affiche les trois premiers sous le nom.
- **Writing manner** : voix, longueur des messages, emoji et formalité, avec un aperçu de la façon dont le personnage parle.
- **Status schedule** : une grille de la semaine indiquant quand le personnage est online, away, do not disturb, unavailable ou offline, avec un petit décalage aléatoire pour que les changements ne tombent pas exactement à la minute.
- **Forum** : rang, signature, fréquence de publication, s’il ouvre ses propres fils et s’il vous répond ou répond à d’autres personnages, rubriques favorites.
- **Habits** : petites manies que le profil ajoute de lui-même après les échanges et les messages. Vous pouvez en ajouter (marquées « yours », elles ne comptent pas dans la limite quotidienne) ou supprimer n’importe laquelle.
- **Model** : le modèle qui écrit comme ce personnage. Par défaut, un profil utilise les modèles de l’application définis dans les paramètres (un pour le Messenger, un pour le Forum). Choisissez-en un autre pour ce seul profil, dans le Messenger comme dans le Forum ; « The app's models (Settings) » revient au réglage par défaut. La liste est la même, avec recherche, que dans les paramètres. « Fill empty » et l’entretien de création de profil utilisent toujours le modèle d’import défini dans les paramètres.

**Profile picture.** Cliquez sur l’avatar en haut de l’éditeur (ou sur « Profile picture… » dans le menu « ⋯ ») pour dessiner un portrait. La boîte de dialogue remplit « What to draw » à partir du nom du profil, de About et des centres d’intérêt ; modifiez-le à votre guise. Choisissez un modèle d’image (celui par défaut du moteur si vous n’en choisissez aucun ; votre propre liste passe en premier) et appuyez sur **Generate**. Pas satisfait ? **Generate again**. **Use this picture** place l’image dans le profil, et **Save** la conserve. L’image apparaît alors dans la liste des profils, dans le Messenger et sur les messages du forum, à la place de la lettre. **Remove picture** revient à la lettre. Le dessin nécessite un modèle d’image configuré dans Molfar Vertep ; sans lui, la boîte de dialogue le signale. L’image est produite par votre propre fournisseur d’images, elle peut donc coûter ce que ce fournisseur facture.

Deux actions se trouvent en haut de l’éditeur. **« Fill empty »** demande au modèle de proposer des valeurs pour les seuls champs vides ; vous voyez d’abord une liste à cases à cocher, et rien ne change tant que vous n’appuyez pas sur « Apply selected ». Le modèle lit le profil enregistré, enregistrez donc vos modifications d’abord si elles doivent compter. **Update from Roleplay** relit la carte, une fois, lorsque vous appuyez dessus, et montre ce qui changerait : About, Writing manner et les nouveaux centres d’intérêt. « Accept changes » les place dans le brouillon ; rien n’est enregistré tant que vous n’appuyez pas sur Save. Habits, les champs du forum et le planning ne sont jamais modifiés. Cela fonctionne pour les profils importés depuis Roleplay ; si la carte a disparu de Roleplay, l’application le dit. Les modifications forment un brouillon : tant qu’il diffère du profil enregistré, une barre en bas affiche « Unsaved changes » avec **Cancel** et **Save**. Quitter avec des modifications non enregistrées demande : enregistrer, abandonner ou rester.

L’application conserve un profil enregistré, qui réapparaît à l’ouverture de l’écran. **« Delete profile »** (le menu « ⋯ », dernier élément) le supprime définitivement après une confirmation ; c’est irréversible. Le profil suivant de la liste s’ouvre.
