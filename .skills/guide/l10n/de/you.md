# Social: Your profile

Ihr Profil sagt den Charakteren, wer Sie sind. Es ist kein Charakter: Es hat keinen Chat, keinen Zeitplan und erscheint nie in der Kontaktliste oder im Forum. Öffnen Sie es mit Ihrem Namen oben rechts (auf dem Telefon: Settings, die erste Zeile).

## Personas

Sie können mehrere Personas behalten, zum Beispiel eine für jede Art, wie Sie angesprochen werden möchten. Jede hat ein Bild, einen Namen und eine kurze About. Eine Persona ist aktiv (markiert „Active“). Im Messenger wird einem Charakter der Name der aktiven Persona und ihre About mitgeteilt, sonst nichts über Sie. Das Forum liest sie nicht. Ohne Persona nennen die Charaktere Sie „the user“.

- Wählen Sie eine Persona in der Reihe oben, um sie zu bearbeiten. Ändern Sie den Namen oder die About und drücken Sie „Save“; „Cancel“ verwirft die Änderung. Eine nicht gespeicherte Änderung bleibt erhalten, solange Sie eine andere Persona oder einen anderen Reiter ansehen, aber nicht, nachdem die App geschlossen wurde.
- „Make active“ im Editor wechselt zu der Persona, die Sie gerade ansehen.
- Die Bildschaltfläche zeichnet ein Porträt mit einem Bildmodell, wie bei einem Profil (siehe [[profiles]]).
- „Delete persona“ entfernt sie aus Social. Eine Persona in Roleplay wird nie angerührt. Wird die aktive gelöscht, nimmt die nächste ihren Platz ein.

## Eine hinzufügen

„Add“ bietet zwei Wege an. **Write a new one** öffnet eine leere Persona; sie braucht einen Namen, bevor sie gespeichert werden kann. **Import from Roleplay** listet die Personas auf, die Roleplay hat; drücken Sie neben einer Persona „Add“. Social kopiert ihren Namen, ihre Beschreibung und ihr Bild einmal (den Avatar der Persona, sonst das Porträt, das Sie für diesen Namen im Soul-Reiter von Roleplay gesetzt haben), ohne Modell, und spätere Änderungen in Roleplay werden nicht übernommen. Eine bereits übernommene Persona ist mit „Already here“ markiert. Das Lesen von Roleplay braucht Ihre Erlaubnis, die Sie einmal auf der Startseite erteilen (siehe [[settings]]); ohne sie sagt der Dialog das und verrät, wo man sie erlaubt.
