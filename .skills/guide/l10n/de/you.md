# Social: Your profile

Ihr Profil sagt den Charakteren, wer Sie sind. Es ist kein Charakter: Es hat keinen Chat, keinen Zeitplan und erscheint nie in der Kontaktliste oder im Forum. Öffnen Sie es mit Ihrem Namen oben rechts (auf dem Telefon: Settings, die erste Zeile).

## Personas

Sie können mehrere Personas behalten, zum Beispiel eine für jede Art, wie Sie angesprochen werden möchten. Jede hat ein Bild, einen Namen und eine kurze About. Eine Persona ist aktiv (markiert „Active“). Im Messenger wird einem Charakter der Name der aktiven Persona und ihre About mitgeteilt, sonst nichts über Sie. Jede Persona hat mit jedem Charakter einen eigenen Chat, mit eigenem Verlauf und eigener Gedächtnisnotiz: Wenn Sie die aktive Persona wechseln, zeigt der Messenger die Chats dieser Persona (der Chat-Kopf sagt „as <name>“, sobald Sie mehr als eine haben). Ein Charakter schreibt nur der aktiven Persona zuerst und antwortet auf eine Nachricht, die Sie in einem beliebigen Chat gesendet haben, auch nachdem Sie gewechselt haben. Das Forum liest sie nicht. Ohne Persona nennen die Charaktere Sie „the user“.

- Wählen Sie eine Persona in der Reihe oben, um sie zu bearbeiten. Ändern Sie den Namen oder die About und drücken Sie „Save“; „Cancel“ verwirft die Änderung. Eine nicht gespeicherte Änderung bleibt erhalten, solange Sie eine andere Persona oder einen anderen Reiter ansehen, aber nicht, nachdem die App geschlossen wurde.
- „Make active“ im Editor wechselt zu der Persona, die Sie gerade ansehen.
- Die Bildschaltfläche zeichnet ein Porträt mit einem Bildmodell, wie bei einem Profil (siehe [[profiles]]).
- „Delete persona“ entfernt sie aus Social zusammen mit ihren Chats und dem, was die Charaktere über sie behalten. Eine Persona in Roleplay wird nie angerührt. Wird die aktive gelöscht, nimmt die nächste ihren Platz ein.

## Eine hinzufügen

„Add“ bietet zwei Wege an. **Write a new one** öffnet eine leere Persona; sie braucht einen Namen, bevor sie gespeichert werden kann. **Import from Roleplay** listet die Personas auf, die Roleplay hat; drücken Sie neben einer Persona „Add“. Social übernimmt ihren Namen und ihr Bild (den Avatar der Persona, sonst das Porträt, das Sie für diesen Namen im Soul-Reiter von Roleplay gesetzt haben), und das Importmodell (Settings, Models) schreibt aus Beschreibung, Titel, Pronomen und Profil der Persona eine kurze About, so wie bei Charakteren: dritte Person, ein paar Sätze, keine {{user}}-Makros, keine sexuellen Details oder Geheimnisse. Das ist ein Modellaufruf, und er geschieht einmal: Spätere Änderungen in Roleplay werden nicht übernommen. Scheitert das Modell, wird nichts hinzugefügt, und der Dialog sagt, warum, sodass Sie es erneut versuchen können. Eine bereits übernommene Persona ist mit „Already here“ markiert. Das Lesen von Roleplay braucht Ihre Erlaubnis, die Sie einmal auf der Startseite erteilen (siehe [[settings]]); ohne sie sagt der Dialog das und verrät, wo man sie erlaubt.
